
> [!important] 핵심 Takeaway
> **목 긴장의 진짜 원인은 "어깨 힘 대신 목 힘을 쓰는 습관"이다. 폼롤러에 꼬리뼈로 앉아 상복부를 홀드한 상태에서 만세 동작을 천천히 반복하면, 어깨가 목 대신 제 역할을 찾아가면서 C1-C2·C7-T1 긴장도가 자연히 떨어진다.**
>
> 임상 핵심: ① 등이 굽은 채 목만 당기면 긴장 더 심해짐. ② 상복부 홀드가 핵심 — 복직근 고정이 없으면 어깨가 흉추를 끌어올림. ③ 수건 경추 3-6번 삽입 → 턱 열림 → 어깨 힘만 독립 사용 가능. ④ 만세 범위·귀-어깨 거리가 대칭화되면 효과 확인 완료.

## 개요

박성규 치료사가 목·어깨 긴장도 높은 환자에게 적용하는 **기본 운동 치료 세팅**. 거북목·일자목·목디스크·승모근 과긴장 환자 모두에 적용 가능한 체형 교정 원리 영상이다. (11:20, [바른몸교수] 목과 어깨 긴장이완 및 체형교정원리)

## 핵심 내용

### 1. 목 긴장이 생기는 두 가지 패턴

**패턴 A: 호흡 시 목 근육 과사용**
- 호흡할 때 흉식호흡 → 보조 호흡근(사각근·흉쇄유돌근) 과활성
- 매 호흡마다 목이 긴장 → 하루 종일 누적

**패턴 B: 어깨 동작 시 목 근육 대리 사용**
- 팔 들기·만세 동작에서 어깨 힘 대신 목 힘을 끌어다 씀
- 어깨 근육(회전근개·중간승모근) 약화가 원인

**왜 "목 뒤로 당기기"만으로는 안 되나:**
```
등 굽음 → 흉추 후만 고착
    ↓
목만 뒤로 당기면 굽은 등이 더 굽어짐
    ↓
오히려 경추 신전근 긴장 증가
```
→ **등 신전 + 어깨 하강**이 선행돼야 목 이완 가능

---

### 2. 비대칭 평가 3단계

**뒤에서 확인:**
1. 귀 끝 → 어깨까지 거리 좌우 비교
   - 거리 차이 = 고개 회전 비대칭 or 어깨 거상 비대칭
2. 만세 동작 좌우 타이밍 비교
   - 한쪽이 먼저·더 많이 올라오면 → 그쪽 어깨 과거상

**촉진으로 확인:**
| 부위 | 위치 | 정상 | 비정상 |
|------|------|------|--------|
| C1-C2 경계 | 턱 라인 아래 후두부 | 양측 동등 | 한쪽만 딱딱 |
| C3-C5 중간부 | 경추 중간 | 대체로 부드러움 | 딱딱 (드묾) |
| **C7-T1 경계** | 목-등 이행부 | 양측 동등 | **한쪽만 단단** ← 핵심 |

> C7-T1(버섯목 정션)이 한쪽만 굳어 있으면 고개가 그쪽으로 약간 회전돼 있는 상태.

---

### 3. 폼롤러 + 만세 운동

**세팅:**
1. 폼롤러를 바닥에 세로로 놓기
2. **꼬리뼈로 걸터앉기** — 좌골이 아닌 미추(coccyx) 위치
3. 발 90도 → 천천히 뒤로 누우며 폼롤러 위에 척추 정렬
4. 다시 무릎 90도로 발 조정

**만세 동작 순서:**
```
① 팔 앞으로 나란히 (90도)
② 천천히 만세 (위로 올리기) — 콘센트릭
③ 천천히 내리기 — 에센트릭
속도: 5~10초씩 (천천히 할수록 효과↑)
호흡에 맞춰서 진행
```

**핵심 관찰:**
- 한쪽 어깨가 먼저 올라오면 → 불균형 확인
- 옷이 딸려 올라오면 → 흉추·복근 과사용 중

---

### 4. 상복부 홀드 기법 (핸즈온)

**왜 필요한가:**
팔을 올릴 때 어깨 힘이 부족하면 복직근이 흉추를 위로 끌어올려 보상 → 어깨가 아닌 몸통이 만세 동작을 함

**방법:**
```
손을 깍지 낀 상태로 흉골(sternum) 하단부에 위치
    ↓
상복부를 아래쪽으로 눌러 고정
    ↓
만세 동작 시행 → 흉추가 따라 올라가지 못하게 제한
    ↓
순수 어깨 근육만 사용 강제
```

**자가 적용:** 깍지 낀 두 손을 흉골 하단에 대고 스스로 홀드하며 동작.

---

### 5. 수건 기법 — 턱 보상 방지

**문제 상황:**
만세 동작 반복 중 어깨 힘이 부족해지면 → 턱을 위로 드는 보상 동작 발생 → 목 긴장 재증가

**해결:**
```
수건을 돌돌 말아 경추 3-6번 뒤에 대기
    ↓
턱이 자연히 앞으로 열림 (chin-forward position)
    ↓
후두하근·흉쇄유돌근 단축 불가 → 턱 들기 보상 차단
    ↓
어깨 근육만 독립적으로 사용
```

---

### 6. Concentric/Eccentric 교차 트레이닝

폼롤러 만세 운동은 단순 동심성(concentric) 운동이 아니라 **콘센트릭 ↔ 에센트릭 교차**:

| 구간 | 수축 형태 |
|------|---------|
| 아래에서 위로 올리기 초반 | 콘센트릭 |
| 중간 지점 이후 | 에센트릭으로 전환 |
| 위에서 내려오기 초반 | 콘센트릭 |
| 내려오기 후반 | 에센트릭 |

→ 치료사가 핸즈온으로 저항을 교차 제공하면 신경근 재교육 효과 극대화.

---

### 7. 운동 효과 확인

**전후 비교 체크리스트:**
- [ ] 앉았을 때 귀-어깨 거리 좌우 대칭
- [ ] C1-C2 촉진 긴장도 감소
- [ ] C7-T1 촉진 긴장도 감소
- [ ] 만세 가동범위 좌우 동시·동등
- [ ] 어깨가 "내려오는" 느낌 (거상 해소)
- [ ] 옆에서 봤을 때 머리 위치가 뒤로 물러남

## 임상 적용

### 대상 환자
- 거북목·일자목으로 목 뒤 뻣뻣함 만성화
- 팔 들기 시 어깨 상방 회전 불충분
- 목디스크로 팔 저림 → 경추 감압 전 근이완 선행
- 굽은등(흉추 후만) + 목·어깨 복합 긴장

### 처방 순서
1. **비대칭 평가:** C1-C2, C7-T1 촉진 → 긴장 부위 확인
2. **폼롤러 세팅** (꼬리뼈 앉기 → 누운 자세)
3. **상복부 홀드 + 만세 5회** (5~10초 속도)
4. **수건 삽입 후 동일 반복** (턱 보상 있는 경우)
5. **효과 확인:** 앉아서 귀-어깨 거리·만세 범위 재평가

### 치료사 없이 혼자 할 때
- 깍지 낀 손으로 흉골 하단 셀프 홀드
- 수건을 경추 3-6번에 고정 후 시행
- **5회 × 2~3세트**, 하루 1~2회

## 한·양방 연결

| 한의학 | 이 운동의 원리 |
|--------|-------------|
| 肩井(GB21) 과긴장 | 어깨 하강 회복 → 자연 이완 |
| 天柱(BL10) 경직 | C1-C2 이완으로 해소 |
| 大椎(GV14) | C7-T1 정션 — 이완 목표 지점 |
| 呼吸과 목 긴장 | 복횡근 활성화 → 보조호흡근 과사용 감소 |

**침 치료 결합:** 肩井·天柱·大椎 침 → 급성 긴장 감소 → 폼롤러 만세 운동으로 기능 회복 유지.
