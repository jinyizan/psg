
> [!important] 핵심 Takeaway
> **엉덩관절은 3뼈(장골·좌골·치골)가 합쳐진 관절로, 천장관절·치골결합·엉덩관절 세 개의 관절이 하나의 '골반대'를 이룬다. Y자 인대(장골-대퇴 인대)가 전방을 강하게 잡고, 궁둥구멍근(piriformis)이 대퇴골두 회전을 조절한다.**
>
> 임상 핵심: ① 치골결합은 연골 구조 → 골반 회전 불균형 흡수. ② PSIS-ASIS 각도 = 골반 경사각. ③ 궁둥뼈 가시가 둥글어 앉기 불균형 원인. ④ 고관절 앞쪽 공간 > 뒤쪽 → 외회전 범위 > 내회전.

## 개요

기능 해부학 시리즈 3번째 영상. 골반대의 뼈 구조, 천장관절, 인대, 근육을 체계적으로 설명한다. (24:32, [바른몸교수] 엉덩관절의 기능 해부학)

## 핵심 내용

### 1. 골반 3뼈 구조

발달학적으로 세 개의 뼈가 합쳐진 하나의 골반뼈:

```
장골(Ilium, 일리움)
  ├─ 장골능(Iliac crest): 벨트 걸리는 능선
  ├─ ASIS (전상장골극): 대퇴직근 부착점. 외부 촉진 가능
  └─ PSIS (후상장골극): 천장관절 경계, 흉요근막 부착

좌골(Ischium, 이스키움)
  ├─ 좌골결절(Ischial tuberosity): 앉을 때 체중 받는 둥근 돌기
  └─ 좌골신경이 이 근방을 통과 → 좌골신경통

치골(Pubis)
  └─ 치골결합(Pubic symphysis): 연골 구조 → 골반 꼬임 흡수
```

**치골결합의 기능:**
- 좌우 골반이 서로 다른 방향으로 회전할 때 꼬임을 분산
- 출산 시 이완·벌어짐 → 아이가 통과할 공간 확보

### 2. 천장관절(SIJ)

**구조:**
- 천골(삼각형 쐐기)이 양쪽 장골 사이에 박힌 형태
- 관절이 아닌 결합 조직으로 잡힌 관절 — 가동성 최소, 안정성 최대

**안정화 인대:**
| 인대 | 위치 | 역할 |
|------|------|------|
| 엉덩허리인대 | L4-5 → 장골능 | 요추-골반 연결 |
| 앞엉치엉덩인대 | 천골 전면 | 전방 안정성 |
| 뒤엉치엉덩인대 | PSIS 부근 | 후방 안정성 |

**흉요근막:** PSIS에서 강하게 잡힘 → 발박수([[자가치료-골반기저근-복압]])가 이 장력에 영향.

### 3. 고관절 주요 인대

**앞면:**
- **Y자 인대(장골-대퇴 인대, Iliofemoral ligament):** Y자 거꾸로 모양. 인체에서 가장 강한 인대 중 하나. 대퇴골두 전방·내측 회전 제한
- **사타구니 인대(서혜인대):** 장요근 텐던 통과. 장력 증가 시 서혜부 통증

**뒷면:**
- **궁둥-대퇴 인대(좌골-대퇴 인대):** 빗살 모양. 내회전 시 수동 장력으로 제한

### 4. 고관절 근육

#### 앞면 근육
```
장요근(Iliopsoas)
  ├─ 대요근(Psoas major): L1~L5 → 대퇴골소결절
  ├─ 소요근(Psoas minor)
  └─ 장골근(Iliacus): 장골와 → 하나의 텐던으로 합류
대퇴직근(Rectus femoris): ASIS → 슬개골
대퇴근막장근(TFL): 장골능 → IT밴드
```

#### 외측 근육
- **중간볼기근(Gluteus medius):** 단각 보행 안정화 핵심
- **소볼기근(Gluteus minimus)**
- **대퇴근막장근 + IT밴드**: 무릎까지 연결

#### 뒷면 근육
```
대볼기근(Gluteus maximus): 엉덩이 신전·외회전
햄스트링(Hamstrings):
  ├─ 반막근(Semimembranosus)
  ├─ 반힘줄근(Semitendinosus)
  └─ 대퇴이두근(Biceps femoris): 2두근
```

#### 심층 회전근 (Deep 6)
- **궁둥구멍근(Piriformis):** 대퇴골두 외회전·굴곡 조절. 좌골신경 위로 주행 → 경직 시 좌골신경통
- 폐쇄근(내·외), 상하쌍둥이근: 골반기저근과 연결

### 5. 골반 경사각과 다리 정렬

**골반 경사 (ASIS-PSIS 연결선):**
- 전방 경사(Anterior tilt): 요추 과전만, 장요근 단축 시
- 후방 경사(Posterior tilt): 요추 평탄화, 햄스트링 단축 시

**Q 앵글과 다리 모양:**
```
고관절 전경각(前傾角, Anteversion) 과다
  → 대퇴골두 앞쪽 기울림
  → 무릎 안쪽 하중 증가
  → X다리(Genu valgum) 경향

전경각 감소(后傾)
  → 무릎 바깥쪽 하중
  → O다리(Genu varum) 경향
```

**고관절 회전 특성:**
- 앞쪽 관절와 공간 > 뒤쪽 → 외회전 ROM > 내회전 ROM
- 굴곡 시 대퇴골두가 뒤로 구르며 앞으로 미끄러짐 (Roll & Glide)

### 6. 엉덩정강근막띠 (IT Band)

```
대볼기근 + 대퇴근막장근
         ↓
    IT 밴드(장경인대)
         ↓
  대퇴골 외측 Gerdy 결절
```

- 과사용 → 외측 대퇴부 마찰 → **IT밴드 증후군** (러너스니)

## 임상 적용

### 서혜부 통증 감별
| 원인 | 특징 |
|------|------|
| 장요근 단축 | 고관절 굴곡 시 재현. 앉기 후 기상 시 통증 |
| 서혜인대 압박 | 장요근 텐션 과다. 임산부에 흔함 |
| 좌골신경통(piriformis) | 엉덩이 심층 압통 → 하지 방사통 |

### 골반 불균형 체크
1. ASIS 좌우 높이 확인
2. PSIS 좌우 높이 확인
3. 앉아서 좌골 압점 비교
4. 치골결합 압통 여부
